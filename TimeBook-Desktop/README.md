# TimeBook 桌面版（Windows）

柳比歇夫时间统计法的 Windows 桌面版，与安卓版同一套统计口径，**备份文件互相通用**。

## 怎么用

- 免安装版：双击 `dist-desktop\TimeBook-2.1.0-桌面版.exe` 即可，无需安装。
- 首次打开会自动建「工作 / 学习 / 生活」三个标签，事项自己建。
- 关掉窗口不会退出，程序就守在右下角托盘里；要彻底退出，右键托盘图标 → 退出 TimeBook。

## 功能

| 模块 | 说明 |
| --- | --- |
| 计时 | 点事项卡片开始；同一时刻只计一件，开始新的会自动结束上一件。结束时可写一句备注（非必填） |
| 提醒 | 事项可设默认目标时长；到点弹 Windows 系统通知，**不会自动结束**，窗口最小化、收进托盘都照常提醒 |
| 记录 | 按天翻看，可补录、改时间、改备注、删除 |
| 统计 | 日 / 月 / 年；按标签汇总并可展开到具体事项；多标签各自计入 |
| 计划 | 月度 / 年度 / 五年（2021 起算）；可给标签或具体事项设目标；到期写总结后归档，历史计划保留快照 |
| 备份 | 导出 / 导入 json，与手机端同格式（schemaVersion 3）；每日自动备份保留 5 份 |
| 托盘 | 关闭窗口退到托盘，计时与提醒继续；托盘菜单能看正在计时什么、一键结束、打开数据文件夹、退出 |

## 托盘

窗口右上角的 × 只是把窗口收起来，程序还在跑，正在计时的时长和到点提醒都不受影响。

- 左键单击托盘图标：显示 / 收起窗口
- 悬停：看到「正在计时：事项名 00:12:34」
- 右键菜单：显示主窗口 / 开始计时…（或 结束计时并写备注…）/ 打开数据文件夹 / 退出 TimeBook

第一次收进托盘时会有一次 Windows 气泡提示，之后不再打扰。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| 空格 | 开始 / 结束计时 |
| Ctrl + Alt + 空格 | 全局唤起窗口并开始 / 结束 |
| Ctrl + N | 新建事项 |
| R | 补录一条记录 |
| Esc | 关闭弹窗 |

## 数据在哪

```
%APPDATA%\TimeBook\data.json        主数据文件（原子写，保留 .bak）
%APPDATA%\TimeBook\backups\         每日自动备份，保留最近 5 份
```

直接复制 `data.json` 就是一份完整备份。

## 和手机互通

桌面版导出的备份与安卓版完全同格式：

1. 手机：事项页 → 备份与恢复 → 导出，得到 `TimeBook-备份-*.json`
2. 电脑：备份与数据 → 从文件导入 → **合并导入**

反向同理。事项、标签、全部记录、计划目标、每期总结与归档快照都会带过去。

### 导入的两种方式

| 方式 | 行为 |
| --- | --- |
| 合并导入（默认） | 本机数据一条不删，只把文件里多出来的事项、记录、计划补进来 |
| 覆盖导入 | 清空本机数据，整体换成文件里的（会二次确认） |

合并的具体口径：

- 标签 / 事项：先按 id + 同名认；id 撞了但名字不同、或名字一样 id 不同，都按名字认作同一个，不会出现两个「读书」
- 记录：同一事项 + 同一开始时间 + 同一结束时间 = 同一条，重复的跳过，不会把时长算两遍
- 未结束的记录（导出时正在计时）不合并，避免出现两条同时在跑
- 计划目标：同一期同一对象只保留一条；数值不一样时默认保留本机，可在导入时勾选「以导入文件为准」
- 归档期：本机没有的补进来；本机已归档的不覆盖，只补空着的总结

导入完成会列出「新增 / 沿用 / 跳过 / 冲突」各多少条，心里有数。

## 开发

```bash
npm install          # 首次
npm start            # 本地运行
npm run dist         # 打包便携 exe（或双击「打包桌面版.bat」）
node tools/test-merge.js   # 只跑合并逻辑的单元自测
```

目录：

```
main.js              主进程：窗口、托盘、本地文件读写、系统通知、单实例
preload.js           安全桥接（contextIsolation）
src/core.js          统计 / 计划 / 快照 / 备份格式 / 合并导入（与 Kotlin 版逐条对齐）
src/app.js           界面与交互
src/index.html       结构
src/styles.css       样式
tools/make-icon.js   生成图标（纯 Node 画 PNG / ICO）
tools/seed.js        写入示例数据（调试用，会覆盖 data.json）
tools/smoke.js       自动冒烟：计时→备注→归档→合并导入→关闭到托盘，并逐页截图
tools/test-merge.js  合并导入的断言测试
```

## 备注

- 计时靠「开始时间戳」表达，关掉应用、关机重启都不会丢，下次打开接着算。
- 只有从托盘菜单选「退出」才会真正结束进程，此时到点提醒才会失效。
