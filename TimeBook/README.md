# TimeBook（时间账本）

一个本地离线的时间开销记录 App，按柳比歇夫时间统计法的思路：**先把要做的事建成「事项」，做的时候点一下开始，结束后自动落账，再按日 / 月 / 年看时间花在哪了。**

原生安卓工程：Kotlin + Jetpack Compose + Room，不联网、不要账号、数据只存在本机。

---

## 一、功能清单

### 1. 事项（可随时编辑）

- 新建事项：名称、颜色、备注、**默认目标时长**（可留空）。
- 任何时候都能改名称 / 颜色 / 备注 / 目标时长，历史记录不受影响。
- 不想再计时可以**归档**：从计时页隐藏，历史统计保留。
- 删除事项会连带删除它的全部记录，界面会二次确认并提示条数。

### 2. 计时

- 底部五个页签：**计时 / 记录 / 统计 / 计划 / 事项**。
- 点任一事项卡片即开始计时；同一时刻只允许一件事，点另一件会自动结束当前这条再开新的。
- 计时只记「开始时刻」，秒表按系统时间实时算：
  **杀掉进程、锁屏、重启手机都不会丢**，重开 App 自动恢复。
- 结束时自动落账，并弹出**「这一段时间在做什么？」备注面板**（v1.2 新增）。
- 支持**补录**：计时页和记录页右下角都能补一段已经过去的时间。

### 2.1 每次执行的备注（v1.2 新增）

- **停止计时后立刻弹面板**：显示事项、`13:15 - 14:50`、已记录时长（设了目标还会标「目标达成 ✓ / 未到目标」），输入框自动聚焦。
- 备注**非必填**：写着方便，不想写点「先不写」即可；留空保存等于清空。
- 快捷词 `顺利 / 被打断 / 走神了 / 状态不错 / 有点累`，点一下以「，」追加，重复点不会重复加。
- **计时中也能写**：计时卡片上一行备注位，有备注显示内容 +「改」，没写显示「这一段时间在做什么，记一句」+「写」。
- **记录页每条都有备注位**：备注独立成浅底块（最多两行），没备注的显示「＋ 加一句备注」，点一下直接改，不用打开完整编辑弹窗。
- 只有主动点「结束计时」才弹面板；**切换事项、通知栏结束不弹**，避免打断下一件事，事后在记录页补即可。
- 备注会跟着备份走（JSON 里的 `note` 字段），换手机不丢。

### 3. 定时提醒（本版新增）

两种方式，二选一，**默认不设 = 不提醒**：

| 方式 | 说明 | 例子 |
|---|---|---|
| 做满时长 | 从开始时刻起满 N 分钟提醒 | 写代码满 45 分钟提醒 |
| 到某时刻 | 到当天某个钟点提醒；该时刻今天已过则按次日 | 15:30 要去开会 |

- 事项目录里可设**默认目标时长**，开始计时时自动带上；计时中还能「改提醒」只改这一次。
- 计时卡片实时显示：`目标 45 分 · 15:42 提醒` + 进度条 + `还剩 12:30`。
- **到点不自动结束**：转成「已超出 03:12」的琥珀色状态，由您决定何时按「结束计时」。
- 到点提醒走**前台服务常驻通知 + AlarmManager 精确闹钟**，锁屏、切后台、App 被划掉都能响；通知上带「结束计时」按钮，可直接结算。
- 记录里会留下目标快照，事后能看到 `目标 45 分 ✓` 或 `未达`。

### 4. 统计

- 日 / 月 / 年三种粒度，左右翻期间。
- 总用时、记录条数；月视图有「每日用时」柱状图，年视图有「每月用时」柱状图。
- **按标签两层展示**：每个标签一张卡，卡头点开是它下面具体事项的次数与用时，可「展开全部 / 收起全部」。
- 月 / 年视图会带上同期计划目标：标签显示「计划 40 小时 · 完成 92%」，展开后每个事项也显示自己的目标进度。
- 没打标签的事项单独归入「未打标签」组，不会漏掉。
- 口径：**跨零点的记录按实际重叠时长拆到它跨越的每一天**，所以「日」加起来正好等于「月」，「月」加起来正好等于「年」，不重不漏。

### 5. 标签与计划（本版新增）

**标签**：事项的上层归类（读书 / 工作 / 生活…），一个事项可挂多个标签，标签也能统计。

**计划**：三个周期 —— **月度 / 年度 / 五年**（五年按 2021 起算对齐：2021–2025、2026–2030…），左右翻页，可「沿用上期」。

计划分两级，**事项目标不会重复计入总目标**：

| 情况 | 总目标怎么算 |
|---|---|
| 只给标签设目标 | 总目标 = 标签目标之和 |
| 标签 + 它下面的事项都设了目标 | 事项目标算「拆解」，总目标仍 = 标签目标之和 |
| 只给事项设了目标、所属标签没设 | 事项目标**计入**总目标 |

- 计划页右上角 **「＋ 新增计划」**（或列表底部虚线行）先选「按标签 / 按具体事项」，再填小时数；已有目标可直接改。
- 卡头点击展开 / 折叠事项；卡头铅笔改标签目标，事项行点开改事项目标。
- **到期 → 写总结 → 归档**：周期结束后页面顶部出现「已到期 · 写总结并归档」，弹窗先给自动统计（完成度、计划 / 实际、次数、每个标签达成率），再填心得（可不写）。
- 归档后该期**目标锁定**，只能看不能改；记录仍可查可改。
- **历史计划**分「待总结 / 已归档」，归档详情可下钻到事项，可改总结、可取消归档（回到本期）。

### 6. 数据

- Room（SQLite）本地存储，`timebook.db`（v5，含 `plan_target` 两级目标与 `plan_doc` 计划档案）。
- 事项页 →「备份与恢复」：能直接看到备份清单（标签 / 事项 / 关联 / 记录 / **计划目标（月/年/五年，标签与事项分开计）** / **计划档案与总结**）、上次备份时间。
- **导出备份**：一个 JSON 文件，含标签、事项、记录、计划目标、**每期总结与归档快照**；换手机后「从文件恢复」即可，导入有二次确认。
- **自动备份**（默认关）：选一个文件夹，每天自动写一份，只保留最近 5 份；靠手动导出容易忘，这个才是换手机的兜底。
- 备份格式 `schemaVersion = 3`，**兼容旧的 v2 备份**（缺计划档案就跳过，计划目标按标签级恢复）。
- 卸载 App 会清空数据（含备份设置），换机前请先把 JSON 转出去。

## 三、编译与安装

### 1. 直接安装（最快）

安装包已打好：**`dist/TimeBook-1.2.apk`**（11 MB，已用本地密钥签名）。

1. 把 APK 传到手机（微信文件传输 / 数据线 / 网盘都行）。
2. 手机上点开安装，系统提示「未知来源应用」时选择允许。
3. 首次启动会申请「通知」权限，**建议允许**，否则到点提醒不会响。

包名 `com.liubishchev.timebook`，最低 Android 8.0（API 26），targetSdk 34。

### 2. 改完代码重新打包（双击就行）

本机已经装好独立工具链（不改系统环境，全部在 `../.tools/` 下）：

- JDK 17：`.tools/jdk17/zulu17.54.21-ca-jdk17.0.13-win_x64`
- Gradle 8.9：`.tools/gradle/gradle-8.9`
- Android SDK（platform 34 / build-tools 34.0.0 / platform-tools）：`.tools/android-sdk`

双击工程根目录的 **`打包APK.bat`**，它会自动设置环境变量、构建 release 版并把产物复制到 `dist/TimeBook-1.2.apk`。全程约 1～4 分钟（首次下载依赖更久）。

> 也可以装 Android Studio 用图形界面打开本目录 Sync + Run；两条路产物一致。

### 3. 签名

- 密钥库：`keystore/timebook-release.jks`，别名 `timebook`，密码在 `keystore.properties`。
- **这两个文件务必自己保管好**：以后升级安装必须用同一把钥匙签名，丢了就只能卸载重装（数据靠导出备份）。
- 两者都已写进 `.gitignore`，不会被误提交。

## 四、权限说明

| 权限 | 用途 | 用户感知 |
|---|---|---|
| `POST_NOTIFICATIONS`（Android 13+） | 发到点提醒和常驻计时通知 | 首次启动会弹授权框；拒绝也能用，只是没有通知 |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` | 计时期间常驻通知 | 通知栏有一条「计时中」 |
| `SCHEDULE_EXACT_ALARM`（Android 12+） | 到点准时提醒 | 系统默认可能不给；没给时提醒可能晚几分钟，App 内会提示 |
| `VIBRATE` | 到点震动 | — |

若提醒不准时：系统设置 → 应用 → TimeBook → 允许「闹钟和提醒」；部分国产系统还需在「电池 / 后台管理」里允许自启动与后台运行。

## 五、已知限制 / 本版没做

- 同一时刻只能计一件事（不支持并行计时）。
- 到点提醒只响一次，不重复提醒。
- 没有云同步、没有多设备，换机靠导出 / 导入 JSON。
- 没有「达标率」统计（目标值已存进记录，后续可加）。
- 重启手机后不会自动恢复闹钟；重开 App 会恢复。
